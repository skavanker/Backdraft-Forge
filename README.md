# Backdraft Forge

A browser-based character creator for Advanced Dungeons & Dragons 2nd Edition. No backend, no account — just open and roll.

**[Try it live](https://backdraft-forge.vercel.app)**

## Features

- Full character creation flow: abilities, race, class, proficiencies, equipment, spells, backstory
- Enforces 2E rules (ability requirements, race/class restrictions, exceptional strength, level limits)
- Level-up wizard with HP rolling, thief skills, spell slots, and proficiency gains
- Dark/light theme with parchment aesthetic
- PDF and printable character sheet export
- Optional AI-generated backstory (Claude, OpenAI, or Ollama)
- Fully static — runs entirely in the browser

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- [Svelte](https://svelte.dev) + [Vite](https://vite.dev)
- SCSS
- Deployed on [Vercel](https://vercel.com)
